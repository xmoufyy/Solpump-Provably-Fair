# Audit 3 - 2026-10-24

Follow-up audit of v2.0.0 (after `COMPREHENSIVE_AUDIT.md`). Scope: crypto/algorithm correctness, status engine, imports, integrity checks, exports, local security, UI. Every fix has a regression test that failed before the fix (checked by reverting `src/` and re-running).

## Algorithms: no defects found

Crash, Blackjack, Keno (v2 + seedrandom v1) and Mines (v2 + v1) were traced against `tests/reference-parity/reference/official.mjs` and the independent Python port. The traces covered the HMAC key and message order, the length-prefixed big-endian transcript, block counters, rejection limits, Crash's full-digest `% 20` and 52-bit formula, Blackjack's `clientSeed + String(n)` from n = 1, and Mines' private-seed key with the `"mines"`, `""` and `"0"` transcript. No change was needed. Three-way parity still reports no divergences in 2,055 cases.

## Quality-of-life improvements

1. **What each conclusion shows, and what evidence is missing.** Each conclusion has plain-language text in the outcome, commitment and timing cells (`EVIDENCE_EXPLANATIONS` in `shared/src/contracts.ts`).
2. **Seed character warnings.** Zero-width, no-break, bidirectional, control and surrounding whitespace characters are named with their code point and position, for server seed, client seed and nonce. The value is never modified.
3. **History view persistence.** Filters and the page number are kept in the URL and restored when you return to History. A "Clear filters" button and a loading state were added.
4. **Trace copy feedback.** "Copied N steps", or a visible failure when the clipboard is blocked. The copy uses the filtered steps when a filter is active.
5. **Stale "saved" notice.** After an edit, the saved-record link says it belongs to the previous inputs.

## Checked and left as is

- **Duplicate or wrong-count reported Keno/Mines values** are classified `mismatch`, as asserted by F-02. Out-of-range Mines positions are `invalid_input`, while out-of-range Keno numbers are `mismatch`. None of these produces a false match. Reclassifying malformed reported values as `invalid_input` is a product decision.
- **Duplicate Mines clicked tiles** are not rejected. They do not affect the derived win or loss.
- **The CSV export** prefixes formula-like cells with `'`. Re-importing a CSV export can therefore alter seeds that start with `= + - @`. Use the JSON export for round trips.
